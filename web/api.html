DEVELOPER REFERENCE

A straightforward review API.

Submit one recording, receive a job identifier, then poll for its result.
Both endpoints require your team key in the X-API-Key header.

POST /api/v1/analyze

Upload one .mov recording as a multipart file field. Returns HTTP 202 immediately after acceptance. The configured upload limit is 100 MB by default.

curl -X POST http://127.0.0.1:8000/api/v1/analyze \
  -H "X-API-Key: YOUR_PRIVATE_KEY" \
  -F "file=@recording.mov"
{ "job_id": "6e3816b1..." }

GET /api/v1/jobs/{job_id}

Poll this endpoint until status becomes done or failed. A job has a 270-second deadline by default, including upload and queue time.

curl http://127.0.0.1:8000/api/v1/jobs/JOB_ID \
  -H "X-API-Key: YOUR_PRIVATE_KEY"
{
  "job_id": "6e3816b1...",
  "status": "done",
  "verdict": "no_violation",
  "violations": []
}
FieldContract
statusprocessing, done, or failed
verdictviolation or no_violation; only present when done
violationsEvent type, timecode_sec, description, and 1–3 evidence_frames
evidence_framestimestamp_sec and image_base64 containing JPEG bytes
descriptionVisible evidence, reasoning, and public rule references

Handle failures explicitly.

Failed processing has no verdict. Missing weights, invalid video, processing errors, and timeouts never become a negative finding.

{
  "job_id": "6e3816b1...",
  "status": "failed",
  "error": {
    "code": "MODEL_UNAVAILABLE",
    "message": "The local analyzer or required weights are unavailable."
  }
}
HTTP statusMeaning
400Missing file, empty file, or malformed multipart upload
401Missing or invalid access key
404Unknown job
408Upload deadline exceeded
413Upload size limit exceeded
415Unsupported file extension
429Processing queue full; retry after the indicated delay

Interface support

GET /health reports availability, configured limits, and whether the analyzer module is present. Module presence does not confirm that weights are loaded.

GET /ui/jobs/{job_id} requires the same key and returns timing information plus structured rule sources for the interface. It does not alter the public jury response.

All processing and interface assets are served locally. Keep your service behind HTTPS when providing a public URL.

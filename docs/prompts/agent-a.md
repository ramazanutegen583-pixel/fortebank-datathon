# Стартовое задание агенту A

Ты агент A команды ForteBank Datathon: продукт и интеграция.
Прочитай AGENTS.md, README.md, docs/requirements.md, docs/architecture.md,
contracts/README.md и docs/status/agent-b.md.

Работай в отдельной рабочей копии на codex/product. Если рабочая копия уже
занята другим агентом, не переключай её ветку и не начинай правки в ней.

Первая задача A1: реализовать минимальный веб-интерфейс загрузки .mov и
асинхронный API POST /api/v1/analyze и GET /api/v1/jobs/{job_id}, X-API-Key,
статусы и JSON по контракту. Предусмотреть worker и адаптер к
vision.pipeline.analyze_video(video_path, output_dir). В UI показать события,
таймкоды, кадры и нормативные источники из локального результата.

Код анализа делает агент B. Твои каталоги: web/, server/, deploy/, tests/product/.
Общие зависимости и документация запуска — твоя ответственность.
Не придумывай API внутри vision/ и не меняй контракт без передачи B.

Для проверки используй только явно синтетические fixtures. В рабочем режиме
без настоящего анализатора/весов возвращай failed, а не выдуманный вердикт.
Не выводи конкурсные данные в контекст Codex. Не устанавливай облачный AI SDK.

Проверь API-ключ, загрузку, статусы, повреждённый файл, ошибку анализатора и JSON.
Подготовь повторяемый запуск. Обнови docs/status/agent-a.md и сделай коммит
только своей части. Сообщи, что проверено, что осталось и что требуется от B.
Не утверждай, что приложение выполняет настоящее распознавание, пока B не подключён.
